Two skills for Claude Code:

| Skill | What it does |
|---|---|
| [`claude-watch`](claude-watch/) | Lets Claude really *watch* a video (TikTok, Reels, YouTube or a file): a timestamped transcript with sound cues, plus a frame taken at the moment each line is said, so pictures and words stay in sync. |
| [`simulated-webinar-chat`](simulated-webinar-chat/) | Makes a realistic placeholder live-chat CSV (WebinarJam export format) timed to a webinar recording, for test runs. It researches real first names for whichever country you choose. |

## Install

1. Click **Code → Download ZIP** on this page and unzip it.
2. Copy the skill folders (`claude-watch`, `simulated-webinar-chat`) into your Claude skills folder:
   - Windows: `C:\Users\<you>\.claude\skills\`
   - Mac/Linux: `~/.claude/skills/`
3. Follow the one-time tool setup in each skill's `README.md`.
4. Restart Claude Code.
